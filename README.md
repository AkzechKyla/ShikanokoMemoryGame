# Shikanoko Memory Game

A simple memory game featuring **Shikanoko Nokonoko Koshitantan**, built using **HTML**, **CSS**, and **JavaScript**.

Play the game here: https://akzechkyla.github.io/ShikanokoMemoryGame/

## Features
- **4x3 Layout**: A grid-based card matching game.
- **Move Counter**: Tracks the number of moves taken.
- **Timer**: Displays the total time taken to complete the game.
- **Main Menu**: Navigate easily before starting the game.
- **Sound Effects & Music**: Features audio from the anime Shikanoko Nokonoko Koshitantan for an immersive experience.

## How to Play

1. Click on a card to reveal it.
2. Match pairs of identical cards.
3. Complete the game in the fewest moves and shortest time possible.
